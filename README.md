# Projeto de Testes QA em Java

Este projeto simula testes manuais em um sistema de login simples.

## Objetivo
Praticar conceitos de QA, como:
- Criação de casos de teste
- Identificação de bugs
- Validação de funcionalidades

## Tecnologias
- Java

## Testes realizados
- Login válido
- Senha incorreta
- Usuário inválido
- Campos vazios

## Bugs encontrados
- Falta de validação de campos vazios
- Mensagens podem ser melhoradas

## Melhorias implementadas
- Validação de campos vazios adicionada
